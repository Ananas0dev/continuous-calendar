# Roadmap

- Replace plaintext password storage with a reviewed password-hashing scheme and migration.
- Audit authentication, note permissions, input limits, CORS, and session expiry.
- Make persistence atomic and add recovery/export tests.
- Separate the large client into maintainable modules while preserving behavior.
- Inventory/pin external integrations and document offline behavior.
- Test the Arabic/English UI, mobile layout, imports, recurring events, and synchronization across browsers.
